Department of Information Technology — VSB Engineering College

About IT Task Manager

IT Task Manager is a student task management, submission, verification and progress tracking platform developed for the Information Technology department of VSB Engineering College. Engineered by Tharunkumar K, the platform streamlines academic task governance, coding competency tracking, automated communication, and departmental analytics for students, student coordinators, class advisors, and department leadership (HOD).

Core Features & Modules

Student Task Management

Students can view academic assignments, filter by category (Competition, Course, Workshop, College Work), and track deadlines in real time.

Task Submission & Verification Workflow

Multi-tier verification workflow supporting individual and team submissions, screenshot proof uploads via Cloud CDN, and feedback with resubmission support.

LeetCode Progress Tracking

Real-time LeetCode problem solve velocity tracking, Easy/Medium/Hard breakdown, dynamic target setting, and automated streak monitoring.

GitHub Progress Tracking

Synchronized tracking of daily and weekly student GitHub commits with combined coding performance analytics.

Team Management

Collaborative group creation for hackathons and group assignments with invite codes, leader badges, and unified submissions.

Telegram & Email Notifications

Automated Telegram Bot alerts (@IT_TaskManager_Alerts_bot), Web Push notifications, and multi-node institutional email dispatches.

Admin & Faculty Management

Role-Based Access Control (RBAC) for Supreme Admin, HOD, Year Coordinators, and Class Advisors with OpenXML Excel reporting.

Project Architecture & Tech Stack

Built with React, TypeScript, Vite, TailwindCSS, Node.js, Express, PostgreSQL, Cloudinary CDN, and Brevo API.
